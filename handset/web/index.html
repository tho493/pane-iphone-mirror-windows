    How to run Pane

    Open-source mirroring for Windows. Everything runs on your PC; the phone stays on USB.

    1

    Prerequisites

    • Windows 10 or 11
    • Python 3.10+
    • Apple Devices from Microsoft Store
    • USB‑C data cable (not charge‑only)
    2

    Install

    git clone <your-repo-url>
cd handset
pip install pymobiledevice3

    On Windows, if pip install pymobiledevice3 fails on native wheels, install the package without optional firmware tools, then run from this repo (it includes small shims).

    3

    Start the server

    python -m handset.server

    Open http://127.0.0.1:8765 in your browser. Keep the terminal open.

    4

    iPhone setup

    • Plug in and unlock the iPhone
    • Tap Trust on the phone
    • Enable Settings → Privacy & Security → Developer Mode and restart
    • Press Start mirroring here (first run may mount a developer image; keep the phone unlocked)

    Pane uses the same display tunnel as Xcode Device Hub, over USB or Wi‑Fi. It does not run iOS on Windows—it streams and controls your physical iPhone.
